# Leexi coverage

Source: Leexi's OpenAPI spec (https://public-api.leexi.ai/v1/openapi.json, the one docs.public-api.leexi.ai is built from)
and its guides at docs.leexi.ai (Public API, API key scopes, Webhooks, Webhook events), swept 24 Nov 2026. Generated by
`bun scripts/openapi-actions.ts leexi`: every operation in the spec is an action (39), plus upload_recording. None has run
against a real Leexi account yet. Composio's Leexi toolkit has 9 tools, all matched by name; it has no triggers.

## Left out

| What | Why |
| --- | --- |
| Nothing in the spec | — |
| Webhooks (call.processed) | Set up by hand in Settings → Advanced → Webhooks; the API can't create one, and deliveries aren't signed. Polled instead |
| Company details ("Read company" scope) | No route for it in the spec yet |

## Hand adjustments

- Lists in the query (owner_uuid, participating_user_uuid, source_id, customer_phone_number, customer_email_address) go as
  `name[]=`, as Leexi's descriptions say (own/leexi/index.ts).
- The reseller's client team and user calls were renamed (create_client_team…): their summaries repeat the company's own.
- request_presigned_url only hands back an upload address, so it runs without asking.
- upload_recording (hand-written): gets the upload address, uploads the file there, answers the recording_s3_key create_call takes. Asks first.
- A `{"success": false}` answer is an error even with a 200.

## Sign-in

| Method | Status |
| --- | --- |
| API key: key ID and secret from Settings → Advanced → API Keys, sent as HTTP Basic | done |
| OAuth | Leexi offers none |

Needs the AI Meeting plan or higher. The key's scopes decide which actions work (a new key has only Read calls); its
access rules decide which calls it sees.

## Triggers (polled, polls/leexi.ts)

| Trigger | How |
| --- | --- |
| new_call | Calls by last change, every 10 minutes; fires once Leexi's AI notes or chapters are there, as its webhook would. Filters: owner, conversation type |
| new_meeting_event | Newest meeting events, every 10 minutes. Filter: origin (calendar, manual, api) |
| meeting_starting_soon | Meetings starting within N minutes, every 5 minutes |
