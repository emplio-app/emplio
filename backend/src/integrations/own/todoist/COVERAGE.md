# Todoist coverage

Source: Todoist's API v1 OpenAPI document, which it publishes only inside `developer.todoist.com/api/v1/`, generated by
`bun scripts/openapi-actions.ts todoist <file>`. 119 operations are actions, plus `sync`. Benchmark: Composio's Todoist
toolkit (84 tools).

## Deliberately left out

| What | Why |
| --- | --- |
| Token revocation and token migration | They end the login the action runs on |
| Cancelling or reactivating the Todoist plan | A billing decision for the person to make in Todoist |

## Auth

| Method | Status |
| --- | --- |
| API token, pasted | done |
| OAuth | not built here; Todoist's tokens don't expire, so it needs only an OAuth app registered |

## Triggers

Polled (`polls/todoist.ts`), because Todoist's webhooks belong to a registered app, not a personal token.
`new_task` and Composio's `new_task_created` are the same trigger; also `task_completed`, `new_project`, `new_comment`.

## Actions

Generated, one per operation, grouped as Todoist groups them. Names follow Composio's where the call is the same.
