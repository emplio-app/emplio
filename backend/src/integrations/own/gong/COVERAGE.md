# Gong coverage

Source: Gong's OpenAPI spec, as its API documentation page (gong.app.gong.io/settings/api/documentation) loads it from
https://gong.app.gong.io/ajax/settings/api/documentation/specs?version=, swept 24 Nov 2026. Generated by
`bun scripts/openapi-actions.ts gong`: every operation but one deprecated is an action (73). None has run against a real
Gong account yet. Composio's Gong toolkit has 58 tools and no triggers; every call it makes is here under a shorter name,
except retrieve_manual_crm_call_associations (/v2/calls/manual-crm-associations), which is no longer in Gong's spec.

## Left out

| What | Why |
| --- | --- |
| assignProspectsCoolOffOverrides | Gong marks it deprecated; assign_prospects_to_flow does the same |
| Webhooks | Gong's webhooks are an action in an automation rule, set up by hand in Gong; the API can't create one. Polled instead |

## Hand adjustments (scripts/openapi/gong.ts, own/gong/index.ts)

- Names come from Gong's summaries without their "(/v2/...)" ending, shortened by hand (list_calls, get_call_transcripts…).
- Lookups that are POSTs run without asking: filtered call and user lists, transcripts, stats, scorecards, tasks, flow steps, call access, the meeting-integration check.
- ask_about_entity and generate_entity_brief only read, so they run without asking, but each use spends Gong AI credits.
- The base URL is per company: the key may start with it; only *.gong.io hosts are accepted, so the key can't be sent elsewhere.
- Gong answers an empty call list with a 404; the polls read that as nothing new.

## Sign-in

| Method | Status |
| --- | --- |
| Access key and secret (Company settings → Ecosystem → API, technical administrators only), sent as HTTP Basic | done |
| OAuth (a Gong app, help.gong.io "Create an app for Gong") | Not built and nothing registered: needs an app registered in Gong and Gong's review before other companies can install it. Its token answer carries the company's base URL (api_base_url_for_customer) |

## Triggers (polled, polls/gong.ts)

| Trigger | How |
| --- | --- |
| new_call | The last day's calls (first page, 100), every 10 minutes. Filters: host, workspace |
| new_answered_scorecard | Scorecards reviewed since yesterday, every 30 minutes. Filters: scorecard, reviewed person |
| new_task | One person's open Engage call tasks, every 15 minutes |
